# Third-party components

The prebuilt runner includes That Open Components / Fragments, Three.js, React and their transitive runtime dependencies, plus web-ifc WASM. Retained bundled license comments and fixture license files remain part of the distribution. The launcher uses Playwright (Apache-2.0), installed as an npm dependency; Chromium is downloaded separately by Playwright and retains its own notices. This repository does not relicense those components.

The small fixture set includes its existing Simple Wall MIT license. External ARC, Castle and downloaded research models are not distributed here.
